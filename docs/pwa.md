# Поддержка Progressive Web App (PWA)

Проект настроен как Progressive Web App (PWA), обеспечивая офлайн-работу, возможность установки и улучшенный пользовательский опыт на мобильных и десктопных устройствах.

---

## Manifest

- **Расположение:** `app/manifest.json`  
- **Назначение:** Описывает название приложения, иконки, цветовую схему и то, как приложение будет выглядеть при установке на устройство.  
- **Иконки:** Находятся в папке `public/icons/` в нескольких размерах для разных устройств.  

---

## Service Worker

- **Расположение:** `public/sw.js`  
- **Назначение:** Управляет кэшированием, офлайн-режимом и фоновыми задачами.  
- **Workbox:** Используется файл `public/workbox-*.js` для реализации продвинутых стратегий кэширования и офлайн-функциональности через [Workbox](https://developer.chrome.com/docs/workbox/).  

---

## Поддержка офлайн-режима

- Service Worker кэширует статические ресурсы и API-ответы, позволяя работать приложению без интернета или при плохом соединении.  
- Пользователь может открывать ранее посещённые страницы и ресурсы даже без сети.  

---

## Установка на устройство

- Наличие `manifest.json` и иконок позволяет пользователям устанавливать приложение на главный экран.  
- В поддерживаемых браузерах появится предложение **«Добавить на главный экран»**.  

---

## Аудит Lighthouse (PWA)

Проект удовлетворяет основным требованиям для PWA:  
- Валидный файл манифеста  
- Зарегистрированный и активный Service Worker  
- Адаптивная верстка  
- Поддержка офлайн-режима  
- Возможность установки с иконкой  

Для проверки можно запустить Lighthouse-аудит в Chrome DevTools и посмотреть раздел PWA.  

---

## Требования

- HTTPS обязателен для работы Service Worker и PWA (кроме localhost).  
- Современные браузеры с поддержкой PWA (Chrome, Edge, Safari, Firefox).  

---

## Стратегия обновления

- Service Worker обновляется автоматически при каждом деплое.  
- Старый кэш очищается и заменяется на новый.  

---

## Ограничения

- Полноценный офлайн-режим ограничен закэшированными маршрутами.  
- Push-уведомления и background sync пока не реализованы.  

---

## Конфигурация PWA в `next.config.ts`

Проект использует плагин [`next-pwa`](https://github.com/shadowwalker/next-pwa) для поддержки PWA.  
Ключевые опции в `next.config.ts`:

```typescript
withPWA({
  dest: 'public',         // Куда будут генерироваться service worker и связанные файлы
  disable: false,         // PWA включён
  register: true,         // Service Worker регистрируется автоматически
  skipWaiting: true,      // Новый Service Worker активируется сразу после установки
  clientsClaim: true,     // Service Worker берёт управление всеми клиентами сразу
})
