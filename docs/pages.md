# 📄 СТРАНИЦЫ

Этот документ содержит обзор всех **страниц приложения** с кратким описанием их назначения.  
Для подробной информации см. отдельные файлы в папке `pages/`.  

👉 Чтобы узнать больше о конкретной странице, кликните по её пути — ссылка откроет соответствующую документацию.

---

## Публичные страницы
- [`/`](./pages/home-page.md) — главная страница с категориями товаров, фильтрами (по цене, ингредиентам), поиском и сторис.  
- [`/product/[id]`](./pages/home-page.md) — страница продукта (может открываться в отдельном роутинге или в модальном окне через параллельный роутинг).  

---

## Процесс покупки
- [`/cart`](./pages/cart-page.md) — корзина: изменение количества товаров, удаление позиций, итоговая сумма заказа и форма для персональных данных.  

---

## Пользовательский профиль
- [`/profile`](./pages/profile-page.md) — страница профиля: изменение имени, email, пароля и выход из системы.
